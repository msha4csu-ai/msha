7주차 · Ch8공기 저항이 있는 낙하: dv/dt = g − γv

세 수치 방법과 해석해 v = (g/γ)(1 − e^{−γt})를 비교합니다. g = 9.8 m/s², 0 ~ 10 s.
관찰해 보기 dt를 절반으로 줄이면 오일러 오차는 약 몇 배 줄까요? 2차 방법(수정-오일러, 룬게-쿠타)은요? (교재 예제 1~3)

5주차 · Ch6이분법과 뉴턴 방법: f(x) = sin x − 1/2 = 0

이분법은 구간 [0, π/2]에서, 뉴턴 방법은 x₁ = 1에서 시작합니다. 참값은 π/6 ≈ 0.5236.
관찰해 보기 오차가 10⁻¹⁰ 아래로 내려가는 데 각각 몇 번이 필요한가요? 로그 눈금에서 이분법은 직선, 뉴턴은 급히 떨어지는 이유는? (교재 예제 1·2)

6주차 · Ch7경사하강법으로 비례상수 H 찾기: v = H·d

잡음이 섞인 자료(합성, 참값 500)에 직선 v = Hx를 맞춥니다. 최소제곱 해 H = Σxy/Σx²와 비교합니다. 학습률이 너무 크면 발산합니다.
관찰해 보기 c를 키우며 H의 값이 진동하다 발산하는 경계를 찾아 보세요. 그 경계는 2/Σx² 와 어떤 관계일까요?

9·10주차 · Ch9·10표적 맞히기: 쏘아 맞추기(할선법)

표적은 R = 100 m. 공기 저항 −γv를 넣을 수 있습니다(수정-오일러, dt = 0.005 s). 버튼으로 할선법이 초기 속력을 찾습니다.
관찰해 보기 γ = 0, θ = 45°에서 찾은 v₀는 약 31.30 m/s입니다(교재 p98). γ를 올리면 같은 표적을 맞히는 v₀가 어떻게 변하나요?

11주차 · Ch11라플라스 방정식의 풀림(완화) 방법

[−1,1]² 영역, 경계 φ = 0, 중앙 도체 φ = −1, 처음 내부 φ = 0.1. 각 점을 이웃 네 점의 평균으로 반복해서 바꿉니다.
관찰해 보기 퍼텐셜이 퍼져 나가는 모습을 보세요. 반복할수록 한 번에 바뀌는 양(최대 변화)은 어떻게 줄어드나요? 같은 코드로 열전도 문제도 풀 수 있는 이유는?

12주차 · Ch12브라운 운동: v′ = −v + η(t)

오일러 방법, η는 [−a, a] 균일 난수(a = √(6T/Δt)). 입력 온도 T와 시뮬레이션으로 잰 ⟨v²⟩를 비교하고, 평균 제곱 이탈 거리를 해석해 2T(t + e^{−t} − 1)와 비교합니다.
관찰해 보기 dt를 키우면 잰 ⟨v²⟩가 입력 T에서 벗어납니다(교재 과제 1). 평균 제곱 이탈 거리는 짧은 시간과 긴 시간에서 각각 어떤 꼴로 자라나요?

13주차 · Ch13점을 뿌려 π 구하기

한 변 2인 정사각형에 점 N개를 뿌려 반지름 1인 원 안의 비율로 π ≈ 4·N₁/N 을 구합니다.
관찰해 보기 N을 10배 키울 때마다 오차는 대략 얼마나 줄어드나요? 같은 N에서 여러 번 뿌려 보며 흩어짐도 보세요.

13주차 · Ch13메트로폴리스 몬테카를로: 이징 모형

40×40 격자, 최인접 상호작용(J = 1, k_B = 1). 노란색 = +1, 어두운 색 = −1. 2차원 정사각격자의 전이 온도는 약 2.27입니다(교재의 전역 상호작용 모형과는 다른 설정, 교재 과제 2 참고).
관찰해 보기 T를 천천히 올리며 질서도 m = |ΣS|/N이 언제 크게 떨어지는지 보세요. 전이 온도 근처에서 덩어리(도메인)의 크기는?

심화 S2 · Ch17SIR 구획모형과 행위자 기반 모형

N = 1000, 처음 감염자 1명, 시간 0 ~ 1000. 선은 구획모형(수정-오일러), 점은 행위자 기반(무작위) 한 번의 실행입니다.
관찰해 보기 R₀ = β/γ가 1을 넘을 때와 넘지 않을 때 무엇이 달라지나요? 행위자 기반에서는 감염자 1명이 시작해도 번지지 못하는 경우가 있습니다. 왜일까요?

14주차 · Ch14시그모이드 퍼셉트론이 AND를 배우는 과정

입력 4개 (0,0) (0,1) (1,0) (1,1), 정답 0 0 0 1. 학습규칙 W → W + α·e·y(1−y)·x, b → b + α·e·y(1−y). 점선은 W₁x₁ + W₂x₂ + b = 0 (결정 경계).
관찰해 보기 XOR로 바꾸면 선 하나로는 나눌 수 없어 오차가 줄지 않습니다. 교재는 어떻게 이 문제를 해결하나요?
